# Troubleshooting

Common issues:
- X11 forwarding not rendering remote GUIs on Windows.
- ROS package resolution errors from incorrect sourced workspace.
- Version mismatch across ROS/libfranka/firmware causing startup or runtime failures.
- Realtime kernel present but permissions/groups not configured.
- Visual-servo detection/calibration mismatch causing unstable motion.

Each issue should be resolved by validating environment, sourcing, and runtime prerequisites before changing code.
