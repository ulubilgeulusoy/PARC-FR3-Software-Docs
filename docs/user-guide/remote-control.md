# FR3 Remote Control

- PARC has a touchscreen laptop labeled **VOLT**, and this laptop can be used to remotely control FR3 workflows.
- This application can be used for both computers, but you must switch branches on the VOLT laptop depending on which FR3 control computer you are targeting.

## Branch Selection by Target Computer

<ul>
  <li>
    If you are controlling FR3 through the Dell Computer (Computer 3), use:
    <ul>
      <li><a href="https://github.com/ulubilgeulusoy/FR3_control_GUI/tree/FR3_Control_Humble">https://github.com/ulubilgeulusoy/FR3_control_GUI/tree/FR3_Control_Humble</a></li>
    </ul>
  </li>
  <li>
    If you are controlling FR3 through the PARC Desktop (Computer 1), use:
    <ul>
      <li><a href="https://github.com/ulubilgeulusoy/FR3_control_GUI/tree/FR3_Control_Jazzy">https://github.com/ulubilgeulusoy/FR3_control_GUI/tree/FR3_Control_Jazzy</a></li>
    </ul>
  </li>
</ul>

## Reliability Note

- This remote-control method is not fully reliable and should not be used as the primary method for human-robot interaction (HRI) experiments.
- It is still useful for testing and demonstration workflows.
