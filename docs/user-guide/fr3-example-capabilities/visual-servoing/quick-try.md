# Visual Servoing

## Quick Try (Before Detailed Setup)

- **Example availability:** this example is already installed on both computers.
- **Repository used for this example:**
  - <https://github.com/ulubilgeulusoy/FR3_visual_servo_examples>
  - This is a C++ application that uses the ViSP library.
  - Check the README section of this repository before trying the example.

### Check Before Continue

- Make sure startup prerequisites are complete and the robot status light is green.
- Make sure the E-stop is available and operational.
- Make sure the Ethernet cable and the Intel RealSense depth camera USB are connected to the computer you are using.

### On Dell Computer (Computer 3)

1. Open an Ubuntu terminal.
2. Run:

```bash
cd FR3_visual_servo_examples
./run_visual_servo_combined.sh
```

### On PARC Desktop (Computer 1)

1. Open an Ubuntu terminal.
2. Run:

```bash
cd FR3_visual_servo_examples
./run_visual_servo_combined.sh
```
