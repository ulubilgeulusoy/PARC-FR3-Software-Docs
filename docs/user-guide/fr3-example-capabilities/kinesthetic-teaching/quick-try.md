# Quick Try

## Quick Try (Before Detailed Setup)

- **Example availability:** this example is already installed on both computers.
- **Repository used for this example:**
  - <https://github.com/ulubilgeulusoy/franka_kinesthetic_teaching_GUI>
  - For Dell Computer (Computer 3), use the `Humble_KT` branch.
  - For PARC Desktop (Computer 1), use the `Jazzy_KT` branch.
  - As of April 2026, the Dell-side line above was noted as the most up-to-date in the slide context; read the branch README before proceeding.

### Check Before Continue

- Make sure startup prerequisites are complete and the robot status light is green.
- Make sure the E-stop is available and operational.
- Make sure the Ethernet cable is connected to the computer you are using.

### On Dell Computer (Computer 3)

1. Open an Ubuntu terminal.
2. Run:

```bash
cd franka_kinesthetic_teaching_GUI
./run_gui.sh
```

### On PARC Desktop (Computer 1)

1. Open an Ubuntu terminal.
2. Run:

```bash
cd franka_kinesthetic_teaching_GUI
./run_gui.sh
```
