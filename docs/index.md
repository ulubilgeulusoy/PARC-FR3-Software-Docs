# PARC FR3 Software Documentation

This website is the central documentation hub for FR3-related software workflows used in the PARC environment.

It focuses on:

- FR3 control system installation guidance
- FR3 user-facing operation guidance
- core software capability mapping for kinesthetic teaching, visual servoing, and control orchestration
- safety and startup context for day-to-day usage

## What You Can Find Here

- **Getting Started**: quick orientation, capability map, core technical basics (ROS 2, workspaces, libfranka, ViSP), and safety guidance.
- **FR3 Control System Installation Guide**: summary context, pre-install checks, recommended installation sequence, and lessons learned.
- **FR3 User Guide**: practical user-facing sections for read-before-proceed notes, computer options, FR3 basics, startup checklist, example capabilities, and remote control context.
- **Appendix**: supporting reference notes and glossary.

## Scope Note

This site is designed to give structured, practical guidance for the PARC FR3 ecosystem. Detailed repository-level deep dives are added progressively in dedicated sections.
